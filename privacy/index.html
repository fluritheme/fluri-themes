This collection website

Fluri Themes is made by František Gejdoš in Slovakia. This homepage introduces our effects and founder. The interactive previews run in your browser. We count public HTML requests in cookie-free daily aggregates: page path, site and a broad referrer category. We do not store IP addresses, query strings, visitor identifiers or browsing histories in these analytics. Recognized bots, prefetches, private routes and requests with Do Not Track or Global Privacy Control are excluded. Aggregate rows are retained for up to 90 days. We do not add analytics cookies, fingerprinting or third-party tracking scripts. Fonts and images are hosted with the site. The copy buttons use the clipboard only when you click them.

Hosting

Cloudflare delivers and protects this website, processing network request data under its service terms. Links to Instagram, LinkedIn, GitHub and npm open their own services; those services have separate privacy practices. The supplied founder portrait and brand artwork are presented with the founder’s authorization.

Winter, Spider & Grinch

The product websites share one private traffic dashboard at fluri.xyz/dashboard. Access uses a secure, HttpOnly, time-limited operator session cookie. Winter and Spider retain their earlier aggregate traffic history. Their runtime packages do not automatically send visitor data or report installations. See Winter’s privacy notice and Spider’s privacy notice.

Older Fluri links

The snow website has moved to winter.fluri.xyz. Older product pages, documentation and downloads redirect there. Legacy API requests are forwarded to the existing Winter service without changing the request origin or weakening its authentication. If you use these private APIs or dashboards, the existing product privacy and session rules apply.
